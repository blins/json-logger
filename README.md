# JSON logger. Prototype

Прототип!

Реализованы бэки для хранения логов StdOut, PostgreSQL

Пример конфигурации config.yaml


## Запуск для отладки

```bash
go run *.go
```

## Использование в своих проектах

Достаточно подключить 

```html
<script lang="javascript" src="http://localhost:8080/static/client.js" ></script>
```
(имя сервера будет вашим)

Для более полного примера смотрите папку examples
 - 01 - назначение логов на конкретный элемент
 - 02 - автоматическое логирование всего документа

 ## Условия использования
 На свой страх и риск. Автор не гарантирует ничего ))
